## 渐进试验

- [ ] WDMS 人工基线正常，且没有意外弹窗或未响应状态。
- [ ] 运行 `python main.py --mode real --limit 1`；人工对照货主名称、整件数、散件数和状态，确认输出位于 `real-trial`。
- [ ] 运行少量货主试验；确认同值货主可正确识别，且没有漏项、重复、错列或旧结果。
- [ ] 运行 24 个货主全量；逐行人工核对全部 24 个名称及两列库存值。
- [ ] 确认文件名、目录、表头、数据行数、排序、任务日期、状态与报表 run_id/摘要对应。
- [ ] 确认程序退出码为 0，WDMS 未出现持续卡顿，程序没有关闭或重启 WDMS。
- [ ] 若以上任何一项失败，停止试运行，修正配置或请求供应商确认，不进入无人值守调度。
