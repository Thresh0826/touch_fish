# 摸鱼小工具 v3：截图定位与直接复制（源码更新包）

本次附件为 **摸鱼小工具源码更新包.zip**，不含Python、第三方库或runtime。请保留 **f1f1deab带环境便携包**及其解压目录；新版可直接借用其中的环境，旧目录、文件和依赖都不会被改写。准确新版源码编号看包外SOURCE_MANIFEST.json，revision为moyu-v3，bundled_dependencies为false。

本地合成测试和独立解压检查不等于Windows现场通过。Windows截图界面、C#/PowerShell、真实控件和远程文件复制仍需你亲自试跑；公司现场不使用联网AI。

## 解压与启动

1. 关闭旧摸鱼工具及其Python选择窗口。保留旧源码、旧便携ZIP、已完整解压的f1f1deab便携目录和目标文件。不要覆盖解压到旧目录。
2. 将本次源码更新包完整解压到新的空文件夹，例如 **MoyuTools_Source_v3**，进入解压后的最外层目录。
3. 双击最外层 **启动摸鱼小工具.bat**，或在该最外层目录打开PowerShell，执行：

`.\启动摸鱼小工具.bat`

4. 第一次会弹文件夹选择框，选择你保留的 **旧便携包解压文件夹**，其中应有WDMS_Cloud_Project；也可直接选择其WDMS_Cloud_Project子文件夹。无需选择python.exe，无需复制runtime，更无需安装依赖。选择记在本机，后续自动复用。
5. 新启动器核验旧便携环境的Python、Tk及表格库，随后使用该解释器运行 **新目录的v3源码**，不会调用旧版界面。预期直接打开摸鱼工具。

若旧便携包还没有解压，先把f1f1deab的“摸鱼小工具带环境便携包.zip”完整解压一次，再选择该目录。不能选择ZIP内部虚拟目录，也不能只解压python.exe。环境缺项时停止并回传错误，不联网下载或重装。

确实只想使用电脑原有Python的高级入口：在新目录的 **WDMS_Cloud_Project** 中打开PowerShell，执行：

`powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\moyu_tools\launch.ps1 -UseExistingPython`

该入口才使用原Python文件选择框；需要Python3.9以上、Tk和openpyxl。正常使用旧便携环境时不需要这个入口。

## 准备表格和页面

保存.xlsx原表，在“表格任务”页选择文件和工作表，点击“导入并预览”。确认条数及前20条中的原表行号、下单日期、单据编号。工具按原表顺序读取；同一天不同合同仍分别处理，不改原表、不排序或合并。日期须为Excel日期或完整年月日文本；编号按文本保留前导零。公式、错误、缺少一项关键字段或不能准确还原的数值会阻止整表导入。

读取所选工作表的全部数据行，**包括隐藏及筛选隐藏的行**；两项关键字段均为空的行不建任务。需要部分数据时先另存为只含这些记录的.xlsx。上限1万条任务、10万工作表行、256列、32MB源表。

手工登录本机WDMS，打开 **送货单检索**，设好货主等固定条件，把上方 **送货单号** 列拖到前面且完整可见。在远程桌面打开Everything，显示搜索框和完整ZIP文件名；可先手工搜一个单号让列表显示一个ZIP，或保持空列表。选择已建立的本地目标文件夹。

每行查询把“生成日期”的开始和截止都设为该行 **下单日期**，把 **单据编号填入合同编号**。不更改其他固定条件，不处理下方合同明细的商品行。

## 两张截图完成定位

到“定位、等待与恢复”页，点击 **首次定位／重新定位**：

1. 选择 **1. WDMS**，从窗口列表选医药仓储系统，点击 **获取／刷新截图**。程序自动标出能可靠找到的日期、合同编号、查询和上方行数；能找到送货单号表头时也会标出。检查绿色标记。
2. 对漏掉或错误的项目，点左侧项目名，再在 **同一张截图** 上点选。日期、合同编号框、查询、上方总行数及送货单号表头是常用项目。其他文字标签、第一行单号位置及整个查询条件区域通常会自动补齐；确实无法推断时才需补点或拖框。校验失败保留已选项，不从头重标。
3. 切换到 **2. 远程桌面**，选择远程窗口并获取截图。在图中拖框选择 **搜索输入框** 和 **ZIP结果列表**。固定菜单区域自动生成；它若包含变化内容，才需重框。无需框结果总数，也无需单独标记ZIP第一行坐标。
4. Everything输入即搜索时不勾“需要回车查询”。点击 **检查并保存定位**。程序自动切换两次窗口做只读检查，不填写条件、不查询、不复制。

没有3秒倒计时，不需要每个标记都回到真实窗口。截图按当前显示比例转换为实际屏幕坐标，包括窗口边框和不同屏幕原点；它只在本机内存显示，不写入文件、不上传。保存的定位只有坐标、窗口身份和必要摘要。

若原生日期、合同编号、上方总行数、表头或单号无法确认，停止并说明哪项未通过，不能把其他数值当单号。远程结果区域应显示完整.zip名称，不含其他业务窗口。窗口、缩放、列布局或远程窗口内的Everything位置改变时暂停，恢复或重新定位后再试跑。

## 直接搜索、直接复制

每行查询仍只提交一次。默认最早30秒后，须已观察到本次鼠标忙碌结束，结果和行数稳定5秒，才能处理；窗口响应或等够30秒都不是独立完成证明。上方送货单一览无记录，记为 **未找到** 并继续；多条或单号不明则暂停。

读取送货单号后，远程只输入一次 **真实单号**，不先搜索测试词。核对输入回读及本次结果稳定；换单号后，仍显示上一条ZIP就继续等待，不复制旧结果。选中结果后全选文件列表，文件剪贴板必须只有一个ZIP，实际文件名须与本次显示结果一致。**不假定ZIP名一定等于送货单号**。

随后直接在选定的 **目标文件夹** Ctrl+V，不使用中转暂存目录、不再执行一次发布移动。只有文件尺寸和时间稳定、Windows写入句柄结束、ZIP目录完整，并保存本任务的文件摘要及完成进度后，才进入下一行。这是复制完成检查，不再反复对ZIP内容做CRC扫描。

已存在同名文件且无本任务一致凭证时暂停，不自动覆盖；同一任务的重复单号只有在已保存文件及凭证一致时才复用。目标文件夹中的其他文件不参与判断，不要求空目录。

先点 **一行试跑**。本行未找到则记录，可试跑下一行；只有实际完成一份ZIP复制才解锁整表。亲自核对日期、合同编号、单号、远程文件及目标ZIP正确后，再点 **开始／继续整表**。

查询上限默认600秒、远程搜索60秒、单文件复制300秒，可调整。停止或超时保留当前阶段和文件；不会重复点击查询或再次粘贴。

## 继续、恢复及旧版本

v3的定位、设置和进度独立放在：

`%LOCALAPPDATA%\MoyuTools\sheet_rows_simple`

f1f1deab旧表格版记录仍在原 **sheet_rows** 目录，没有转换、删除或覆盖；便携ZIP及旧解压目录保持原样。旧版暂存任务需用旧版本核实完成，不把它直接转换成v3的直接复制任务。两个版本和库存Demo仍共用执行锁，不能并行自动操作。

v3续跑不需重新导入原表，使用保存的表格快照和同一目标、定位。上次查询状态不明时先核实，不重发；已发粘贴时只检查同一个目标文件，不重新粘贴。窗口重开或移动后先重新定位，再“沿用旧进度”，并通过本次定位的一行闭环。

“查看处理记录”显示原表行号、日期、合同编号、未找到/完成/未完成、单号和实际ZIP名。未完成行不会算成功。已完成文件缺失或变化会暂停。

只有确认WDMS查询及资源管理器复制均已结束，且正常继续无法恢复时，才点 **确认重做当前行**。完整ZIP应使用继续；不完整副本在目标目录改名为 **recovery_任务标识_随机编号_原文件名** 保留，再允许重新搜索、粘贴。文件占用或改名失败就停住，不删除、不覆盖。

## 失败时回传

出错点 **停止**，等待原查询或复制结束；不要反复点查询、粘贴或删改未完成文件。启动和定位失败，可在任意PowerShell执行：

`explorer.exe "$env:LOCALAPPDATA\MoyuTools\sheet_rows_simple"`

启动失败：回传错误画面、存在时的 **portable_startup.json**，附本次源码包外 **SOURCE_MANIFEST.json**。目录打不开或文件缺失直接说明；不用复制或重装环境。

定位失败：回传 **calibration.jsonl**，存在时附 **bridge_startup.txt**。截图本身不保存，无需默认回传业务画面。

运行失败：用 **打开日志** 进入本次任务目录，回传 **events.jsonl**，以及本轮 **请求编号.console.txt**、存在时对应的 **请求编号.result.json**、**请求编号.watch.json**，并附SOURCE_MANIFEST.json。

不默认回传原表、业务ZIP、settings/binding/progress/request、borrowed_runtime.json或凭据。公司现场由你实施，日志先按允许范围脱敏；WorkBuddy只接触你放入固定交接文件夹的允许资料。
